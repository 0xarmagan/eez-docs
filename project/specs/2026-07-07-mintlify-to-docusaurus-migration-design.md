# EEZ Docs: Mintlify → Docusaurus Migration

**Date:** 2026-07-07
**Source:** [0xarmagan/mintlify-docs](https://github.com/0xarmagan/mintlify-docs) (main branch, 23 content pages)
**Target:** this repo (0xarmagan/eez-docs), private for now

## Goal

Migrate the full EEZ protocol docs site from Mintlify to Docusaurus, preserving URL structure, navigation grouping, and branding, using native Docusaurus idioms wherever one exists.

## Repo & scaffold

- Docusaurus classic template, JavaScript (not TypeScript) — matches the source's plain MDX, no type-checking need.
- Branding from `docs.json`: site name "Ethereum Economic Zone", primary `#6366F1` / light `#818CF8` / dark `#4338CA` mapped to `--ifm-color-primary*` variables, favicon from `favicon.svg`, logo images (`01-mark-on-black.png`, `02-mark-on-purple-50.png`, `eez-logo-ref.png`, `eez-logo.png`) copied to `static/img/`.
- Footer socials (GitHub `eez-association`, `eez.io`, X `@etheconomiczone`) and navbar GitHub link (`eez-core-protocol`) carried over from `docs.json`.
- Note: this spec and future plan/scratch files live under `project/` at repo root, not `docs/` — `docs/` is reserved as the actual Docusaurus content folder for the default docs instance.

## Navigation — two docs-plugin instances

Mirrors Mintlify's two top-level tabs and preserves every existing URL, so cross-links between pages need no rewriting.

| Mintlify tab | Docusaurus instance | `path` | `routeBasePath` | Source pages |
|---|---|---|---|---|
| Documentation | default (no `id`) | `docs` | `/` | `introduction`, `quickstart`, `architecture`, `concepts/*`, `guides/*`, `tools/*`, `reference/*` |
| Contract Reference | `id: 'contracts'` | `contracts` | `/contracts` | `contracts/*`, `contracts/interfaces/*` |

- `index.mdx` (not present in either Mintlify nav list — it's the landing page) becomes `src/pages/index.mdx`.
- Navbar items link to each instance's first doc via `docsPluginId`.
- Sidebars are hand-written (`sidebars.js` / `sidebarsContracts.js`), not autogenerated, to preserve Mintlify's exact grouping:
  - Documentation: Get Started (introduction, quickstart, architecture) / Core Concepts (concepts/*) / Guides (guides/*) / Tools (tools/*) / Reference (reference/*)
  - Contract Reference: L1 Contracts (eez, rollup, bridge) / L2 Contracts (eezl2) / Interfaces (contracts/interfaces/*) / Data Types (data-types)

## Content conversion mapping

Verified against current Docusaurus docs (v3.10.1) before finalizing — one candidate mapping (built-in Card component) turned out not to exist and was corrected below.

| Mintlify | Docusaurus | Notes |
|---|---|---|
| `<Warning>` | `:::warning ... :::` | Built-in admonition |
| `<Info>` | `:::info ... :::` | Built-in admonition |
| `<Note>` | `:::note ... :::` | Built-in admonition |
| `<CardGroup>` / `<Card>` | Plain Markdown bold-link bullet list | No built-in card-grid component exists in Docusaurus core/classic theme. Only 2 files affected: `index.mdx`, `introduction.mdx`. |
| `<Steps>` / `<Step>` | `## Step N — Title` headings | Matches the convention `quickstart.mdx` already uses without the component. Applies to: `guides/build-execution-entries.mdx`, `guides/post-verify-batch.mdx`, `guides/bridge-tokens.mdx`, `guides/flash-loans.mdx`, `tools/visualizator.mdx`, `tools/trace-decoder.mdx`. |
| `<Accordion>` / `<AccordionGroup>` | Native `<details><summary>...</summary>...</details>` | Works directly in MDX, no import needed. |
| `<ParamField>` / `<ResponseField>` | Markdown table: `\| Name \| Type \| Description \|` | Matches the Constants/Errors tables already used in the same contract-reference pages. |
| `import UnauditedWarning from '/snippets/unaudited-warning.mdx'` | Partial doc `docs/_unaudited-warning.mdx`, imported by relative path | Underscore-prefixed files under a docs-plugin `path` are ignored by sidebar/routing (confirmed). Imported from both instances — since MDX imports resolve on-disk relative paths (not gated by plugin-instance boundaries), files under `contracts/` import via a `../docs/_unaudited-warning.mdx`-style relative path adjusted for depth. |

## Front matter

- `title`, `description` — unchanged.
- `sidebarTitle` → `sidebar_label` (confirmed correct Docusaurus field name).

## Assets

- `favicon.svg` → `static/img/favicon.svg`, referenced in `docusaurus.config.js`.
- `images/*.png` → `static/img/`.

## Out of scope (this migration)

- Hosting/deploy target (GitHub Pages vs. Vercel vs. Netlify) — decide once the site builds and runs locally.
- Visual parity beyond what native Docusaurus components support (e.g. no attempt to pixel-match Mintlify's Aspen theme).
