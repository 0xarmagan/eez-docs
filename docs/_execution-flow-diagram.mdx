**Phase 1 — L1: prove, queue, execute the call.** The sequencer pre-computes the trace and proof, EEZ verifies and queues it, then `HelloWorldL1`'s call routes through the proxy and back:

```mermaid
sequenceDiagram
    participant Seq as Off-chain Sequencer
    participant EEZ as EEZ Registry
    participant Proxy as CrossChainProxy
    participant AppL1 as HelloWorldL1

    Seq->>EEZ: postAndVerifyBatch()
    Note right of EEZ: Verify proof, queue entry
    AppL1->>Proxy: helloL2World()
    Proxy->>EEZ: executeCrossChainCall()
    Note right of EEZ: Verify hash, apply delta
    EEZ-->>Proxy: "World"
    Proxy-->>AppL1: "World"
```

**Phase 2 — L2: same L1 block, executed independently.** The system address drives the L2 side of the same call, verified against its own rolling hash:

```mermaid
sequenceDiagram
    participant Seq as Off-chain Sequencer
    participant EEZL2 as EEZL2
    participant AppL2 as HelloWorldL2

    Seq->>EEZL2: executeIncomingCrossChainCall()
    EEZL2->>AppL2: getWord()
    AppL2-->>EEZL2: "World"
```
