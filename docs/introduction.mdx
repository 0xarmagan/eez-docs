Ethereum Economic Zone is a smart contract protocol for synchronous composability between Ethereum rollups. Today, cross-rollup logic runs through lock-and-mint bridges, oracle messaging, or relayers — all multi-block, all with their own trust assumptions. Because [based rollups](/reference/glossary#based-rollup) share Ethereum's L1 sequencer, EEZ can instead pre-compute a cross-rollup call's full outcome off-chain, verify it on-chain with a proof, and execute it atomically in a single L1 block — a contract on one rollup calls a contract on another and gets the return value in the same transaction, as if both lived on the same chain.

## How it works, in brief

A batch of [`ExecutionEntry`](/reference/glossary#executionentry) records — each committing to a full cross-rollup call including calls, returns, and state deltas — is posted to L1 via `postAndVerifyBatch` and verified by a per-rollup [multi-prover configuration](/concepts/multi-prover). Verified entries land in per-rollup queues as either [transient or deferred](/reference/glossary#transient-vs-deferred) work, and are consumed in the same L1 block through [`CrossChainProxy`](/concepts/cross-chain-proxy) contracts that preserve `msg.sender` identity across chains. Every entry carries a [`rollingHash`](/concepts/rolling-hash) that catches any deviation from the pre-committed execution. See the [Architecture](/architecture) page for the full call-flow diagram.

## Who should use EEZ?

- **Rollup operators** building based rollups: register with EEZ to expose your rollup to the composability network.
- **DApp developers** building cross-rollup apps (unified DEX liquidity, cross-chain lending, atomic NFT swaps, [cross-rollup flash loans](/guides/flash-loans)): use EEZ's execution model to write cross-chain logic as naturally as same-chain calls.
- **Protocol researchers** studying synchronous composability, based sequencing, and multi-prover verification: EEZ is a concrete implementation to read, extend, and critique.
