# Ethereum Economic Zone

**A contract on one rollup calls a contract on another and gets the return value in the same L1 block** — atomic cross-rollup composability, verified on-chain. No lock-and-mint bridges, oracles, or relayers in the path.

## How EEZ works, in brief

Because [based rollups](/reference/glossary#based-rollup) share Ethereum's L1 sequencer, EEZ pre-computes a cross-rollup call's outcome off-chain, proves it on-chain, and executes it atomically:

- **Post & verify** — a batch of [`ExecutionEntry`](/reference/glossary#executionentry) records (each committing to a full cross-rollup call: calls, returns, and state deltas) is posted to L1 via `postAndVerifyBatch` and verified by a per-rollup [multi-prover configuration](/concepts/multi-prover).
- **Queue** — verified entries land in per-rollup queues as either [transient or deferred](/reference/glossary#transient-vs-deferred) work.
- **Consume** — they execute in the same L1 block through [`CrossChainProxy`](/concepts/cross-chain-proxy) contracts that preserve `msg.sender` identity across chains; every entry's [`rollingHash`](/concepts/rolling-hash) catches any deviation from the pre-committed execution.
